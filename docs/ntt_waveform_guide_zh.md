# NTT 仿真波形解读指南（`ntt_roundtrip.vcd`）

本文说明 NTT 正变换 + 逆变换（round trip）的仿真波形怎么看：选哪些信号、各信号代表什么，以及**怎样只看波形就能证明 NTT 引擎工作正确**。

文中的时间和数值都取自实际仿真结果，与 `simulate_result/logs/ntt_roundtrip_*.txt` 一致。

---

## 1. 这个仿真证明了什么

测试平台对未修改的 `ntt_engine` 做了三件事：

1. 装入一个随机多项式 a（256 个系数，取值 0–3328，随机种子 2026）；
2. 做**正变换 NTT**，读出结果，与 Python 参考实现 `ref/kyber_math.ntt_forward` 逐个比对；
3. 在同一份数据上做**逆变换 INTT**，读出结果，检查是否**还原成 a**。

`simulate_result/logs/ntt_roundtrip_result.txt` 的结论：

```
RESULT: PASS   (NTT vs ref/kyber_math.ntt_forward: match; INTT(NTT(a)) == a: yes)
NTT : start sampled at t = 2610 ns, done at t = 11720 ns, 911 cycles
INTT: start sampled at t = 14300 ns, done at t = 25980 ns, 1168 cycles
```

在波形上可以用第 6 节的五个步骤逐一验证：输入正确、节奏正确、单次蝶形运算正确、输出正确、往返还原。

## 3. 看波形前需要知道的四件事

1. **时间单位**：VCD 用 ps，日志用 ns。日志中的 2,645 ns 对应波形中的 2,645,000 ps。时钟周期 10 ns，上升沿在 10 ns 的整数倍处。
2. **名称信号是 ASCII 字符串**：`state_name`、`layer_name`、`mode_name`、`pingpong` 请设为 ASCII 显示。如果你的工具只能显示十六进制，用**附录**的对照表翻译，例如 `42465f4f5645524c4150` = `BF_OVERLAP`。
3. **读数时把光标放在时钟周期中间**（例如 2,645 ns，而不是 2,640 ns）。在上升沿那一刻，工具可能显示变化前的值，也可能显示变化后的值。
4. **读出结果时看 `ext_dout` 的数值序列**：测试平台在时钟下降沿改变 `ext_addr`，RAM 在下一个上升沿（半个周期后）才给出该地址的数据，所以 `ext_dout` 总是比 `ext_addr` 晚半个周期变化。最简单的读法是**按顺序看 `ext_dout` 依次出现的值**，它们就是第 0、1、2 … 个系数。

## 4. 信号选择表

推荐程度：★★★ 组会必放 ／ ★★ 讲细节时用 ／ ★ 调试用。

### 4.1 控制与进度（顶层）

| 信号 | 格式 | 含义 | 推荐 |
|------|------|------|------|
| `clk` | 二进制 | 时钟，周期 10 ns | ★★ |
| `start` | 二进制 | 启动脉冲（1 个周期） | ★★★ |
| `mode_name` | ASCII | `NTT`（正变换）/ `INTT`（逆变换） | ★★★ |
| `busy` | 二进制 | 引擎正在运算 | ★★ |
| `done` | 二进制 | 完成脉冲（1 个周期） | ★★★ |
| `cycle_count` | 十进制 | 从 start 开始经过的周期数，`done` 时就是总延迟（911 / 1168） | ★★★ |

### 4.2 层与节奏（顶层标注）

| 信号 | 格式 | 含义 | 推荐 |
|------|------|------|------|
| `layer_name` | ASCII | 当前层，如 `NTT  L3 len= 32`；缩放到整个变换能看到 7 段 | ★★★ |
| `layer_no` | 十进制 | 层号 1–7，不在层内时为 0 | ★★ |
| `state_name` | ASCII | 状态机状态：`LAYER_INIT` → `BF_PRIME` → `BF_OVERLAP` → `BF_FLUSH` | ★★★ |
| `bf_len` | 十进制 | 蝶形距离 len：每对系数的下标之差（128, 64 … 2） | ★★ |
| `bf_groups` | 十进制 | 本层分组数（1, 2 … 64） | ★★ |
| `group`、`j_offset` | 十进制 | 当前组号、组内位置 | ★ |
| `bf_count` | 十进制 | 本层已完成的蝶形运算次数，每层数到 128 | ★★★ |
| `pingpong` | ASCII | 本层数据流向：`A->B`（从 RAM A 读、写 RAM B）或 `B->A` | ★★ |

### 4.3 蝶形运算数据（`dut` 层）：用来手算验证

同一个 `BF_OVERLAP` 周期里，下面 7 个信号**属于同一次蝶形运算**：

| 信号 | 格式 | 含义 | 推荐 |
|------|------|------|------|
| `src_dout_a` | 十进制 | 输入 a（偶数位系数，从源 RAM 读出） | ★★★ |
| `src_dout_b` | 十进制 | 输入 b（奇数位系数，与 a 的下标相差 len） | ★★★ |
| `zeta_reg` | 十进制 | 旋转因子 ζ（从 `ntt_rom` 取出） | ★★★ |
| `bf_even_out` | 十进制 | 输出 a′ | ★★★ |
| `bf_odd_out` | 十进制 | 输出 b′ | ★★★ |
| `wr_addr_even`、`wr_addr_odd` | 十进制 | a′、b′ 写回的地址，两者相差 len | ★★ |
| `ramb_we_a`、`ramb_din_a`（或 `rama_*`） | 二进制 / 十进制 | 目标 RAM 的**写使能**和写入数据 | ★★ |

- 正变换（Cooley–Tukey）：a′ = (a + ζ·b) mod 3329，b′ = (a − ζ·b) mod 3329
- 逆变换（Gentleman–Sande）：a′ = (a + b) mod 3329，b′ = ζ·(b − a) mod 3329

### 4.4 外部读写口（顶层）

| 信号 | 格式 | 含义 | 推荐 |
|------|------|------|------|
| `ext_we` | 二进制 | 外部写使能：装载输入多项式时为 1 | ★★ |
| `ext_addr` | 十进制 | 系数下标 0–255 | ★★★ |
| `ext_din` | 十进制 | 写入的系数 | ★★ |
| `ext_dout` | 十进制 | 读出的系数，比 `ext_addr` 晚半个周期变化 | ★★★ |

## 6. 在波形上证明 NTT 工作正确（五步）

### 步骤 1：输入装载正确

- 信号：`ext_we`、`ext_addr`、`ext_din`
- 20 – 2,580 ns 期间 `ext_we` = 1，`ext_addr` 从 0 数到 255。
- 前几个 `ext_din` 为 **487、1308、2058 …**，与 `ntt_roundtrip_result.txt` 中 "Input polynomial a" 的第一行相同：

  ```
  [  0]  487 1308 2058 2096 2650  420  914 2461 ...
  ```

### 步骤 2：节奏正确（7 层，每层 130 个周期）

- 信号：`layer_name`、`state_name`、`bf_count`、`cycle_count`、`done`
- 正变换的每一层都是：

  ```
  LAYER_INIT (1) → BF_PRIME (1) → BF_OVERLAP (127) → BF_FLUSH (1) = 130 周期
  ```

- 每层结束时 `bf_count` = **128**：128 次蝶形运算，处理全部 256 个系数，也就是**每周期完成 1 次蝶形运算**。
- 各层时间：

  | 层 | len | 组数 | 开始 (ns) | 结束 (ns) | 周期 |
  |----|-----|------|-----------|-----------|------|
  | L1 | 128 | 1 | 2,610 | 3,910 | 130 |
  | L2 | 64 | 2 | 3,910 | 5,210 | 130 |
  | L3 | 32 | 4 | 5,210 | 6,510 | 130 |
  | L4 | 16 | 8 | 6,510 | 7,810 | 130 |
  | L5 | 8 | 16 | 7,810 | 9,110 | 130 |
  | L6 | 4 | 32 | 9,110 | 10,410 | 130 |
  | L7 | 2 | 64 | 10,410 | 11,710 | 130 |

- `done` 在 **11,720 ns** 拉高，此时 `cycle_count` = **911** = 7 × 130 + 1。
- 逆变换 7 层的 len 顺序反过来（2 → 128），之后多一段 `INTT SCALE`（257 个周期，把每个系数乘以 128⁻¹ mod q）。`done` 在 25,980 ns，`cycle_count` = **1168**。
- `pingpong`：正变换各层依次为 `A->B`、`B->A`、`A->B` … 交替。7 是奇数，所以结果停在 RAM B，逆变换从 `B->A` 开始。这就是**乒乓 RAM**：每层从一块读、往另一块写，读写互不冲突，才能每周期做一次运算。

### 步骤 3：手算一次蝶形运算（最有说服力）

把光标放在 **2,645 ns**（正变换第 1 层，`BF_OVERLAP`），读 `dut` 层的信号。本节的数都是**十进制**；如果你的工具默认显示十六进制，请对照右列，或把显示格式改成十进制（Unsigned / Decimal）：

| 信号 | 十进制 | 十六进制显示 |
|------|--------|--------------|
| `src_dout_a` (a) | **1308** | `51c` |
| `src_dout_b` (b) | **37** | `025` |
| `zeta_reg` (ζ) | **1729** | `6c1` |
| `bf_even_out` (a′) | **2030** | `7ee` |
| `bf_odd_out` (b′) | **586** | `24a` |
| `wr_addr_even` / `wr_addr_odd` | 1 / 129 | `01` / `81` |
| `ramb_we_a` / `ramb_din_a` | 1 / 2030 | `1` / `7ee` |

手算：
- ζ·b = 1729 × 37 = 63,973
- a′ = (1308 + 63,973) mod 3329 = 65,281 − 19 × 3329 = 65,281 − 63,251 = **2030** ✓
- b′ = (1308 − 63,973) mod 3329 = −62,665 + 63,251 = **586** ✓

同时还能看出：
- a = 1308 正是输入的第 1 个系数，b = 37 是第 129 个系数（日志 `[128]` 一行的第 2 个数）。第 1 层的蝶形距离是 128，正好把下标 1 和 129 配成一对。
- 结果写到地址 1 和 129（相差 len = 128），`ramb_we_a` = 1 表示写入 RAM B，与 `pingpong` = `A->B` 一致。

再举两个例子，可以任选一个展示：

| 时刻 | 层 | a | b | ζ | a′ | b′ | 手算 |
|------|----|---|---|---|----|----|------|
| 10,445 ns | NTT L7 | 2811 | 1803 | 17 | **172** | **2121** | 17×1803 = 30,651；2811+30,651 = 33,462 → 33,462 − 10×3329 = 172；2811−30,651 = −27,840 → +9×3329 = 2121 |
| 14,325 ns | INTT L1 | 1298 | 2694 | 2154 | **663** | **897** | 1298+2694 = 3992 → −3329 = 663；2154×(2694−1298) = 2154×1396 = 3,006,984 → −903×3329 = 897 |

- 10,445 ns 这一次写到地址 1 和 3，得到的 172 和 2121 正是**最终 NTT 结果**的第 1、3 个系数（最后一层直接写出最终结果）。
- 14,325 ns 的输入 1298、2694 正是 NTT 结果的第 0、2 个系数（逆变换的输入就是正变换的输出）。
- 十六进制显示时：10,445 ns 处 a、b、ζ、a′、b′ 为 `afb`、`70b`、`011`、`0ac`、`849`；14,325 ns 处为 `512`、`a86`、`86a`、`297`、`381`。

### 步骤 4：NTT 输出正确

- 信号：`ext_addr`、`ext_dout`（11,720 ns 以后）
- `ext_dout` 依次出现的值：

  | 时间 (ns) | 11,720 | 11,740 | 11,750 | 11,760 | 11,770 | 11,780 | 11,790 |
  |-----------|--------|--------|--------|--------|--------|--------|--------|
  | `ext_dout` | **1298** | **172** | **2694** | **2121** | **2219** | **3192** | **1108** |

- 与日志中 "Hardware NTT(a)" 和 "Reference ntt_forward(a)" 两行对照（这两行完全相同）：

  ```
  [  0] 1298  172 2694 2121 2219 3192 1108 3117 ...
  ```

### 步骤 5：往返还原（INTT(NTT(a)) = a）

- 信号：`ext_addr`、`ext_dout`（25,980 ns 以后）
- `ext_dout` 依次出现的值：

  | 时间 (ns) | 25,980 | 26,000 | 26,010 | 26,020 | 26,030 | 26,040 | 26,050 |
  |-----------|--------|--------|--------|--------|--------|--------|--------|
  | `ext_dout` | **487** | **1308** | **2058** | **2096** | **2650** | **420** | **914** |

- 与步骤 1 装进去的数（`487 1308 2058 2096 2650 420 914 …`）完全相同，说明逆变换把数据精确还原了。

## 7. 讲解词参考

> 这是 NTT 引擎的仿真。输入一个随机多项式，先做正变换，再做逆变换。
>
> 第一张图是全景：7 层，每层 130 个周期，蝶形距离每层减半，数据在两块 RAM 之间来回倒，总共 911 个周期；逆变换多一段乘以 128⁻¹ 的缩放，共 1168 个周期，都与设计值一致。
>
> 放大一层，状态机是 INIT、PRIME、127 个 OVERLAP、FLUSH，蝶形计数正好数到 128，说明流水线每个周期完成一次蝶形运算。
>
> 任取一个周期手算：a = 1308，b = 37，ζ = 1729，按 Cooley–Tukey 公式算出 2030 和 586，和硬件输出一致，而且写回地址也对。
>
> 最后读出结果，与 Python 参考实现一致；再做逆变换，读出的正好是原始输入。所以 NTT 引擎功能正确。

## 8. 常见问题

| 问题 | 解答 |
|------|------|
| 名称信号显示成十六进制 | 设为 ASCII 显示，或查附录对照表 |
| 数值和文档对不上（例如 `51c` 而不是 1308） | 工具在用十六进制显示。文档里的数都是十进制，把显示格式改成十进制（Unsigned / Decimal）即可；0x51c = 1308 |
| `ext_dout` 和 `ext_addr` 对不上 | `ext_addr` 在下降沿变，`ext_dout` 在下一个上升沿才变，相差半个周期。按顺序读 `ext_dout` 的数值即可 |
| `BF_PRIME` 周期里 `bf_even_out` 也有值，但没有写入 | 这是组合逻辑随输入变化的结果；`BF_PRIME` 时写使能为 0，数据不会写入 RAM。只有 `BF_OVERLAP` / `BF_FLUSH` 才写 |
| `bf_count` 在第一个 `BF_OVERLAP` 周期显示 0 | 它计的是"已完成"的次数，在周期结束的时钟沿才加 1 |
| 为什么逆变换多 257 个周期 | 1 个 `SCALE_INIT` 加 256 个周期的缩放（每两个周期处理两个系数） |
| NTT 的 911 和 Encaps 里 `RUN_NTT` 的 914 为什么不同 | Encaps 里的 914 包含 kyber_top 调度引擎的 3 个周期开销 |

## 附录：十六进制 → 文字对照表

显示格式为十六进制时，名称信号会显示成下面右列的数字。

| 文字 | 十六进制 |
|------|----------|
| `IDLE` | `49444c45` |
| `LAYER_INIT` | `4c415945525f494e4954` |
| `BF_PRIME` | `42465f5052494d45` |
| `BF_OVERLAP` | `42465f4f5645524c4150` |
| `BF_FLUSH` | `42465f464c555348` |
| `SCALE_INIT` | `5343414c455f494e4954` |
| `SCALE_READ` | `5343414c455f52454144` |
| `SCALE_WRITE` | `5343414c455f5752495445` |
| `DONE` | `444f4e45` |
| `NTT` | `4e5454` |
| `INTT` | `494e5454` |
| `A->B` | `412d3e42` |
| `B->A` | `422d3e41` |
| `INTT SCALE` | `494e5454205343414c45` |
| `NTT  L1 len=128` | `4e545420204c31206c656e3d313238` |

`layer_name` 的规律：正变换以 `4e545420204c`（`NTT  L`）开头，逆变换以 `494e5454204c`（`INTT L`）开头；紧接着的一个字节是层号，`31` = 1、`32` = 2 … `37` = 7。
